How-to Guides
=============

Task-oriented recipes, grouped by workspace. Each guide assumes basic familiarity
with EMStudio (see :ref:`tutorial`) and helps you reach one objective.

- :doc:`files/index`: open, save and reopen; a project folder; integrate another
  file; find missing files; clean the file; pin a version.
- :doc:`bring-in/index`: files as documents, a geophysical stack, a GraphML matrix,
  a table through a mapping, StratiMiner, a DosCo folder.
- :doc:`stratigraphy/index`: units and their relations, groups, layout,
  chronology, many units at once, filters.
- :doc:`sources/index`: the provenance of files, documents and media on a unit,
  regions traced on images, anomalies traced on geophysical slices.
- :doc:`space/index`: georeferencing, models and tilesets, colours and legend,
  placing objects, containers and epochs.
- :doc:`sheets/index`: fill the recording sheet and print the sheets.
- :doc:`archive/index`: files on disk and in the room, the shelf, versions for
  each use, consolidation for a target.
- :doc:`narrative/index`: write the story, show the graph in it, draft with AI,
  export.
- :doc:`rooms/index`: sign in, create a room, bring a file into a room, enter and
  share it, open it in the other editor.
- :doc:`extensions/index`: live work with EM Tools in Blender, a .blend from the
  graph, vocabularies, packages and plugins, repositories and signatures, the
  Python console.

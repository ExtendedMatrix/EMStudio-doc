Commands no menu draws, and where they are
------------------------------------------

These commands are not drawn in any menu: they live where they serve. The command search (``Edit ▸ Search commands…``, :kbd:`F3`) finds each of them by its name and shows the place written here.

.. list-table::
   :header-rows: 1
   :widths: 24 34 42

   * - Command
     - Where it is
     - What it does
   * - Open in place of the open files…
     - File ▸ Open (its box «in place of the open files»)
     - Choose a file, then close the open ones (asking for those with unsaved changes) and open it
   * - Bring in…
     - File ▸ Bring in… (one of its choices)
     - Bring in — files into the study as documents: what each is, the document, its date, the epoch it represents
   * - Bring in a folder…
     - File ▸ Bring in… (one of its choices)
     - Bring a folder in: read as DosCo, or by an extension that reads folders (a stack of geophysical slices, say)
   * - Read as DosCo…
     - File ▸ Bring in… (one of its choices)
     - Bring in a DosCo folder: each file with an EM id (D.12…) becomes the document of that id — its date, its licence, its role asked in one block
   * - StratiMiner
     - File ▸ Bring in… (one of its choices)
     - StratiMiner: build a graph from a folder of unstructured sources, via the reviewable em\_data.xlsx table
   * - Add node…
     - Matrix header ▸ Add ▾ · ⇧A
     - Add a node (⇧A)
   * - Check the chronology…
     - Matrix header · the ▲ of the status bar
     - The epochs on a time axis, the overlaps with their delta and their remedies
   * - Colours…
     - Preferences ▸ Colours · the Space's Colours ▾
     - The Colours window of the active Space: colour the proxies by type, epoch or a property
   * - Vocabularies…
     - Preferences ▸ Vocabularies · the Inspector's values
     - The vocabularies installed on this computer, those this file uses, and the copy of their terms in the file
   * - Extensions…
     - Preferences ▸ Extensions
     - Settings ▸ Extensions: what EMStudio knows and does — vocabularies, forms, colours (data) and commands, readers, Space layers and tools (code), from the repositories you trust

Mode
----

The mode, the node and the room are no longer a menu of the top bar: their one place is the section **Where you work** of the chip's menu, opened by the left label of the status bar (:kbd:`⇧⌘L`). In a room that menu also uses the two gestures below, which stay in the page, hidden; their labels and tooltips are these.

.. list-table::
   :header-rows: 1
   :widths: 24 20 56

   * - Button
     - When
     - What it does
   * - Open this room in…
     - only in a room
     - Open the same room in the other editor — the graph is the room's, so nothing is transferred
   * - Share this room…
     - only in a room
     - Who is at this table, and whose the live copy is. Opens the node's panel for this room, in a new tab — that is where the ACL and the owner live, and where people, teams, invitations and the transfer are all in one place. EMStudio used to draw its own; it showed people but not teams, so it was retired.

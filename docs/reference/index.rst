Reference
=========

The parts of EMStudio described one by one: the workspaces and the windows, the
menus and the keys, the settings and the Inspector, what differs between desktop
and web, and the files EMStudio reads and writes.

What a script can do, through ``import em``, is in a reference of its own,
generated from the code: the `EMStudio Python API
<https://docs.extendedmatrix.org/projects/emstudio-python-api/en/latest/>`__.
:doc:`/extending/index` tells how a package or a plugin uses it.

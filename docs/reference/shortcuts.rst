Keyboard shortcuts
==================

.. TODO MAN02: complete the prose above the generated tables.

Every key and gesture of EMStudio, grouped by where it acts. The same list is in
the application under ``Help ▸ Shortcuts``, where you can search it. A key that
acts on the graph acts on the canvas and the Outliner, and leaves a focused field
or button alone; keys in the Space follow Blender's.

The keys are given as the Mac shows them and as Windows and Linux show them. A
gesture (a click, a drag, the wheel) is the same on every platform.
